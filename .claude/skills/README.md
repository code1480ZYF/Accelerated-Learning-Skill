# Accelerated Learning Toolkit — Prompt Templates

Three AI prompt templates for generating structured learning notes. Bilingual (EN/ZH).

| Template | EN | ZH |
|----------|----|-----|
| Subject Deep-Dive | [`specific-subject.md`](specific-subject.md) | [`specific-subject-zh.md`](specific-subject-zh.md) |
| Science Preview | [`science-preview.md`](science-preview.md) | [`science-preview-zh.md`](science-preview-zh.md) |
| Reading Notes | [`reading-notes.md`](reading-notes.md) | [`reading-notes-zh.md`](reading-notes-zh.md) |

## Usage

Copy the content of any template and paste it into your AI assistant. Follow the prompts to choose your persona and depth level, then provide source material if needed.

## Customization

These are plain markdown files. Edit them directly to adjust word counts, add sections, change personas, or modify workflows.
